# ma plateforme de tickets wifi zone
projet personnel de MADOU JEROME, vente de tickets en ligne

## Comment ça marche

1. Le client se connecte au réseau Wi-Fi de la zone.
2. Il est redirigé vers la page de vente des tickets.
3. Il choisit un ticket et le paie par Mobile Money.
4. Après le paiement, il reçoit ses identifiants (nom d'utilisateur et mot de passe).
5. Il saisit ces identifiants et accède à Internet.
